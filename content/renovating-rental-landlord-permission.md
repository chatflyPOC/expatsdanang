# Renovating Your Rental: What You Can Change & Landlord Permission

**Published:** September 2026 | **Read time:** 4 minutes

Want to paint the walls or fix that broken cabinet? This guide explains what landlords typically allow, what requires permission, and what you can't touch.

## Permission Levels: What Requires Asking

### GREEN (You Can Do Without Asking)

These changes don't damage the property; expect no objection:

| Change | Why OK | Notes |
|---|---|---|
| **Hang pictures/art** | Removable; small nail holes | Use removable hooks if possible |
| **Curtains/blinds** | Easy to remove; restore original state | Landlord may already own curtain rods |
| **Furniture rearrangement** | Doesn't alter space | Move as you wish |
| **Removable shelving** | No permanent installation | Adhesive-backed shelves OK |
| **Plant/decorations** | Temporary | Don't leave permanent marks |
| **Replace light bulbs** | Landlord expects tenants to maintain | Restore with original type |
| **Minor furniture repairs** | Small fixes (tighten screws, rehang drawer) | Don't replace major components |
| **Clean/organize** | Improves condition | Go ahead freely |

---

### YELLOW (Get Permission First)

These changes might affect property value; ask landlord before proceeding:

| Change | Why Permission Needed | How to Ask |
|---|---|---|
| **Paint accent wall** | Color choice; landlord may want to restore | "Can I paint [wall] a neutral color [show color sample]? I'll repaint white before leaving." |
| **Temporary shelf installation** | Uses removable adhesive but affects wall | "I want to add floating shelves using adhesive. Okay?" |
| **Adhesive tile backsplash** | Landlord may not like it; takes time to remove | "Can I add peel-and-stick tiles in kitchen? Easy to remove." |
| **Change curtain rod** | Permanent holes; affects wall | "Can I move the curtain rod to a different wall?" |
| **Install small fan** | Fan adds holes; heat discoloration | "I want to add a fan above the bed. Okay?" |
| **Rearrange AC unit** | AC is technically landlord's; could break | "Can I adjust the AC position for better airflow?" |
| **Install shelving on wall studs** | Uses drywall anchors; permanent | "I'd like to install shelves for storage. Can I?" |

**Approach:** Friendly email with photo of proposed change; show it's reversible.

---

### RED (Never Do Without Permission)

These changes damage the property or break the lease:

| Change | Why Forbidden | Consequence |
|---|---|---|
| **Paint all walls** | Landlord wants original color on move-out; you forfeit deposit | Risk: -$300+ deposit |
| **Remove cabinets/fixtures** | Alters unit permanently; reduces rental value | Risk: Eviction + lawsuit |
| **Install permanent shelving** | Requires drywall anchors; leaves holes | Risk: Damage charge on move-out |
| **Change locks** | Landlord loses access; security risk | Risk: Immediate eviction |
| **Remove flooring** | Major damage; expensive to repair | Risk: Lawsuit |
| **Tile walls/kitchen** | Landlord didn't authorize; can't be undone easily | Risk: Full deposit forfeiture |
| **Install AC unit** | Landlord's property; unauthorized modification | Risk: Damage charge + broken AC |
| **Cut/drill studs** | Structural damage; landlord's liability | Risk: Major repair costs |
| **Install washer/dryer outlet** | Electrical work; property damage; insurance risk | Risk: Eviction + lawsuit |

## Landlord's Renovation Obligations

### Landlord MUST Fix (Your Rights)

| Issue | Landlord Responsibility | Timeline |
|---|---|---|
| Broken AC (in summer) | Fix or replace immediately | 1–3 days (emergency) |
| Plumbing leak (water damage) | Repair within 3–5 days | Urgent |
| Broken toilet | Fix within 1–2 days | Urgent |
| Non-functioning lights/outlets | Repair within 3–7 days | Non-urgent but standard |
| Broken door lock | Fix within 1–2 days | Security issue |
| Roof/major structural leak | Fix immediately to prevent water damage | Emergency |

**Your action:** Email landlord: "The [item] is broken. Can you repair it this week?" Follow up in 5 days if no response.

### You Should NOT Expect Landlord to Fix

| Issue | Why You Pay | Cost |
|---|---|---|
| Worn carpet | Normal wear after 2+ years | $200–400 to replace |
| Faded paint | Normal wear; tenant can request paint during lease | Free if landlord agrees |
| Squeaky door hinges | Minor maintenance | $10 for lubricant |
| Clogged drain (hair/soap) | Tenant caused | $20–30 to unclog |
| Burnt-out light bulbs | Tenant expected to replace | $2–5 per bulb |

## Permission Email Template

**Subject:** Permission Request: [Specific Change]

"Hi [Landlord],

I'd like to make a small change to the apartment to improve daily comfort. I want to [specific change: paint bedroom accent wall blue / add floating shelves on bedroom wall / install small fan above bed].

I'll use [specific method: water-based paint / removable adhesive / temporary installation] so it won't damage the walls. I'll restore everything to original condition before moving out.

Is this okay with you? Let me know if you have any concerns.

Thanks,
[Your name]"

**Why this works:**
- Specific (not vague)
- Shows reversibility (landlord knows you'll restore)
- Asks clearly (yes/no answer)
- Professional tone (landlord respects you)

## Paint Restoration: How to Remove Paint on Move-Out

### If Landlord Allows Paint, You Must Restore

**Neutral color to repaint:** Landlord typically wants walls white or off-white on move-out

**Painting process:**
1. Buy paint in landlord's original color (or ask landlord: "What color should I repaint?")
2. Ask landlord to provide paint can/receipt from original paint job (or get white primer + paint)
3. Paint carefully; use painter's tape (avoid bleeding onto trim)
4. Landlord inspects before you move out

**Cost:** $30–50 for paint + supplies

**Time:** 4–6 hours labor (DIY) or $50–100 for professional painter

## What to Do If Landlord Says No

**Scenario:** You ask to paint; landlord refuses.

**Your options:**

1. **Accept the wall color** (not worth fighting over)
2. **Use removable solutions:**
   - Peel-and-stick wallpaper (adhesive-backed; removable)
   - Fabric wall hangings (no nails needed; use adhesive strips)
   - Poster frames (hang with adhesive hooks)
3. **Negotiate compromise:** "Can I use peel-and-stick wallpaper instead of paint?" (usually yes)
4. **Renegotiate lease:** "If I can paint, I'll stay another 6 months" (creates incentive for landlord)

## Move-Out Restoration Checklist

Before you leave, restore:

- [ ] Paint walls back to original color (or white)
- [ ] Removed any shelving; fill nail holes with spackle
- [ ] Remove any adhesive residue (use rubbing alcohol)
- [ ] Restore curtain rods to original position
- [ ] Remove any temporary installations (fans, etc)
- [ ] Clean all surfaces (paint is done; now deep clean)
- [ ] Take photos proving restoration

**Why:** Landlord can't charge you for "damage" if you've already restored everything.

## FAQ

**Q: Can I paint if it's in my lease?**
A: Only if lease explicitly says "tenant may paint." Most leases say "restore original color on move-out." Permission is safer.

**Q: Can I install a ceiling fan?**
A: Ask landlord first. Most okay with it if you restore original fixture on move-out.

**Q: Can I remove the kitchen cabinets?**
A: No. Cabinets are landlord's property. Don't touch them.

**Q: What if landlord doesn't respond to my permission request?**
A: Wait 1 week; follow up once. If no response after 2 weeks, assume "no" and skip the change.

**Q: Can I charge for repairs I made?**
A: Usually no (considered part of rent). But document improvements (photos) for reference.
